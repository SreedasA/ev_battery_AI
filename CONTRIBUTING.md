# Contributing

This is a personal research and portfolio project, but clean suggestions are
welcome.

Good contribution areas:

- better video false-positive filtering
- improved ROI selection
- clearer evaluation plots
- deployment improvements
- frontend usability fixes
- documentation cleanup

Please avoid adding dataset images, videos, trained weights, or generated runs
to the repository. Those files are intentionally ignored because they are large
and project-specific.

For code changes, keep the style simple and practical. The priority is domain
correctness and clear logic — this is an applied CV system for a specific
industrial problem, not a general-purpose framework.
